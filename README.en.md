````markdown
# React + Vite + TypeScript Starter Template

An optimized starter template for Single Page Applications (SPA) built with React 19, Vite 8, Tailwind CSS v4, and Radix UI.

## Tech Stack

- **Core:** React 19, TypeScript, Vite 8
- **Styling:** Tailwind CSS v4, Radix UI, Lucide Icons
- **Routing:** React Router v7
- **State:** Zustand (Client) + TanStack Query v5 (Server)
- **Forms:** React Hook Form + Zod
- **Code Quality:** ESLint 9, Prettier, Husky, Vitest

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

Start dev server:

Bash
npm run dev
Build for production:

Bash
npm run build
Folder Structure
src/components/ui/: Reusable UI components.

src/features/: Isolated domain modules.

src/hooks/: Global custom hooks.

src/lib/: Global clients configuration (QueryClient, helpers).

src/routes/: Route definitions.

src/store/: Client global state with Zustand.
````
