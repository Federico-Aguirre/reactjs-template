# Context for AI Agents & Assistant Tools

## Tech Stack

- Frontend: React 19, TypeScript (Strict Mode), Vite 8
- Styling: Tailwind CSS v4, CVA, clsx, tailwind-merge
- Routing & State: React Router v7, Zustand, TanStack Query v5
- Forms & UI: React Hook Form, Zod, Radix UI, Sonner, Lucide Icons

## Development Guidelines

- Always preserve strict typing in TypeScript. Avoid `any`.
- Modularize domain logic in `src/features/`.
- Maintain separation between visual components and data-fetching hooks.
